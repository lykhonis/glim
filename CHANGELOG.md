# Changelog

Glim uses semantic versioning. The version is `project(glim VERSION x.y.z)` in `CMakeLists.txt`, and `packages/glim-web/package.json` matches it. `CHANGELOG.md` has a section for that version. `pnpm release-check` fails if the section is missing, or if a header is added or removed under `packages/*/include` without updating `cmake/public-headers.txt`.

Before 1.0, a new minor version may change the API. A patch version does not.

The public C++ API is those headers. A configured package installs the headers of the targets it built, including one shell. Anything else — sources, examples, tools — is not public. `@glim/web` exports `GlimCanvas`.

Changes land under `## [Unreleased]`. To release, rename it to `## [X.Y.Z] - date`, open a new empty `[Unreleased]` above it, and add a `[X.Y.Z]` link to the tag at the bottom; `pnpm release-check` fails if a section has no link. Pushing the tag `vX.Y.Z` publishes the changelog section as a GitHub release. The tag does not publish to npm. `pnpm web-pack` is a dry run; the tarball is a CI artifact.

## [Unreleased]

- Composition first (K89, `AGENTS.md`): effects are recipes of general primitives. A reflection is the content drawn again under `transform` (flip), `fade` and `inert`; there is no reflection feature.
- `transform({...})`: one tag for translate, rotate, scale (negative flips), skew and 3D tilt about an anchor, with `fit` to keep the result inside the node's box. It replaces `rotate` and `tilt`; `translate(dx, dy)` stays as shorthand. Paint and hit testing share `transformMatrix`; custom elements push `transformAt`. `PushRotate` and `PushTilt` are gone: `PushTransform` carries the matrix (op archive v9, which still reads v8 rotate and tilt).
- `fade({.edge, .length, .fromAlpha, .toAlpha})` ramps a subtree's alpha from an edge inward, over the new paint `GroupParams::fade` (software and GPU). `inert()` keeps a subtree out of hit testing, focus and a11y.
- Native views compose too: a seat drawn twice is reported as a copy (`SlotPlacement::copies`), and a fade over a seat as its `fade`. `shell::SlotFrame` carries both; macOS and iOS show the first copy with a replicator and mask each drawing. Other shells show the view alone for now.
- Webview example: a designed offline page, Flat/Tilt/Skew/Swing motions with an amount slider, and a live reflection built by composition. The chrome fits a phone, and the Android Texture page renders at its plate's size instead of the window's.
- Tag factories: `transform` takes its tag struct like `glass` and `shadow`.
- Glow is a recipe: `glow(sink, box, radius, color, intensity)` records a Plus blend over a radial fill. `effectGlow`, `EffectTag`, `EffectKind`, the `PushEffect` op and the sink's `pushEffect` are gone; op archives up to v9 still read a glow scope as those two ops.
- Edit menu actions (N8.3): `textActions(edit, rules, canPaste)` lists the `TextAction`s (cut, copy, paste, select all) that apply now; secure fields never offer cut or copy. It is the one rule a Glim-drawn menu and shell menus share.
- `glim/shell/ImeEdits.h`: `imeCompose`, `imeCommit`, `imeSelect` and `imeDeleteSurrounding` turn IME edits phrased in UTF-16 against the field (Android's `InputConnection`, the browser) into `TextInputChange`s.
- Android apps launch `com.glim.shell.GlimActivity`, a shell-owned `NativeActivity` subclass every APK now ships, so the shell can reach Java-only platform APIs (the IME's `InputConnection`, the clipboard). `package-android-apk.mjs` compiles several Java dirs into one `classes.dex`; an example's own Java joins the shell's.
- `glim/shell/Utf16.h`: `utf16Units`, `utf16Byte` and `utf16Bytes` convert between UTF-16 positions (UIKit, Android, the browser) and the field's UTF-8 bytes; the Apple bridge now uses them.
- tvOS text input (N8.7): focus never opens the keyboard; Select on a focused field opens the system keyboard on a hidden `UITextField`, whose edits replace the field's text (a secure field starts it empty). The UIKit text view and a11y bridge tests now also run on the tvOS simulator in CI.
- Long-press edit menu (N8.3): a press held 0.5s within the tap slop (`kTextTapSlop`, now shared with tap counting) on a focused field selects the word and opens the edit menu (`Screen::held`, `Screen::holdTick`); the host checks it each frame while a press is held.
- Right-click edit menu (N8.3): `Screen::contextPress` keeps a selection it lands in (else places the caret) and opens the menu at `Screen::menuAt` over a focused field; any press closes it. The host overlays it (`host::withEditMenu`), fixes its actions at open (`host::editMenuActions`) and carries out a pick through the clipboard (`host::runEditAction`, `host::ClipboardAccess`). Shells that report `PointerButton::Right` (Wayland) open it.
- `editMenu(x, y, actions, pick)` (`glim/toolkit/EditMenu.h`): the edit menu Glim draws where the platform has none, composed from `row`, `tap`, `lines`, `glass` and `translate`; `textActionLabel` names each action.
- `textActionStep(action, edit, rules, pasted)` turns an edit menu action into a clipboard write and a `TextChange`, so the host only does the clipboard I/O.
- Text field caret blink and horizontal scroll (N8.3): the caret holds steady after a press, key or text change, then blinks in half-second phases, and stays on under reduce motion (`Screen::caretOn`, `Screen::caretSince`; `paintScreen(..., caretOn)`). The host repaints on each phase flip only while a field is focused. A value wider than its field scrolls to keep the caret inside (`FieldGeometry::scroll`, `textX`); paint, caret, highlight, underline and hit testing share it, and the field clips its text. `FieldGeometry::offsetAt` now takes the `TextEdit`.
- Shift-click from real input: `shell::Event::shift()` is set on pointer presses by macOS and iOS (hardware keyboards) and the host passes it to `Screen::pointerDown`, so Shift-click extends a field's selection.
- iOS text input (N8.6): `GlimTextView` is the UIKit `UITextInput` client for the focused field (keyboard, IME composition, UIKit-set selections and replacements in UTF-16, secure entry, the edit menu). Hardware Cmd+Z, Shift+Cmd+Z, forward delete and word or line deletes go through `TextCommands.h`. `TextOp::Select` / `TextInputOp::Select` set a platform-chosen range, snapped to clusters. Copy, cut and paste live once in the shared Apple bridge for macOS and iOS.
- Clipboard contract (N8.4): `glim/shell/Clipboard.h` declares `readClipboard` and `writeClipboard` (`ClipboardStatus` Ok, Empty or Unsupported), defined by every shell. macOS (`NSPasteboard`) and iOS (`UIPasteboard`) implement it; tvOS, Android, Linux, web and custom answer Unsupported until wired. macOS copy, cut and paste go through it.
- macOS text commands (N8.5, part): `shell::TextInputOp` mirrors `DeleteForward`, `SelectWord`, `Undo` and `Redo`, and `TextInputChange` carries `TextInputUnit` and `extend`. `glim/shell/TextCommands.h` maps the Cocoa text-system command names (word, line and document moves and deletes, their `AndModifySelection` forms, undo and redo) to changes; macOS `doCommandBySelector:` uses it, and the Edit menu gains Undo and Redo. Cut is refused in secure fields.
- Text field pointer (N8.3, part): a tap places the caret at the nearest cluster boundary, a drag selects, a double tap selects the word, a triple tap selects all, and Shift-click extends (`Screen::pointerDown(..., shift)`, `PointerDown::shift`). The selection paints a highlight under the text. `pressText`, `dragText` and `FieldGeometry::offsetAt`/`highlight` are the model and geometry. Pointer events carry the `Engine` they were dispatched under, so handlers measure text as paint does.
- Text editing model (N8.2): `TextOp` adds `DeleteForward`, `SelectWord`, `Undo` and `Redo`; `TextChange` carries a `TextUnit` (character, word, line, document) and `extend`. Moves and deletes step grapheme clusters (combining marks, emoji modifiers, ZWJ sequences, flags, CRLF). `TextEdit` keeps a reversed selection and a coalescing undo history (depth 100). `TextRules` (`maxLength` in clusters, `accept`, `secure`) is set on `TextField::rules`; secure fields paint bullets, mask their a11y value and shell state (`TextInputState::secure`), and refuse copy. New: `copyText`, `shownText`, `shownOffset`.
- Clear glass is a material: `glass({.material = GlassMaterial::Clear})` replaces `glass({.clear = true})`, and sinks' `pushGlass` loses its `clear` argument. Op archive v10 drops the flag; older archives read a clear plate as the Clear material.
- `scaleAlpha(rgba, a)` in `glim/toolkit/Color.h` is the one alpha-scaling rule; the host's `detail::scaleAlpha` is gone.
- Fixed: nested isolates, such as a faded reflection inside a tilted page, crashed on Vulkan. An inner isolate's render target could move the outer one's. Pool targets and Vulkan images now stay put as their pools grow.
- Fixed: a group's bounds ignored its children's transforms, so a flipped or moved child inside an isolate was clipped away.
- Fixed: the software packet rasterizer painted half-resolution (3D) isolates at the wrong scale.
- Android webview on the emulator: the emulator's GPU layer never shows GL-written virtual-display buffers to Vulkan, so the page is copied through the CPU there. Devices keep the zero-copy import.

## [0.1.0] - 2026-11-12

First versioned release of the public packages.

- CMake package, Apple xcframework, Android prefab AAR, and `@glim/web` (loader and glass wasm).
- Public C++ headers are the files under `packages/*/include`, listed in `cmake/public-headers.txt`.
- Every bundle ships `LICENSE` and `THIRD_PARTY_NOTICES.md` (Inter, stb, volk), generated by `node tools/notices.mjs --write`.
- `host::Config::power`: frame-rate cap and low-power mode.
- `pushOpacity`: fades everything painted until the matching `pop`. A lone fill or image folds the fade into its color, with no offscreen pass.
- Tag factories take named params: `glass`, `shadow`, `effectGlow` and `rotate` take their tag struct (`glass({.radius = 16, .tint = t})`). `glassClear`, `glassMetal` and `glassWater` are gone; use `glass({.clear = true})` or `.material`. `glim-lint` now rejects tag factories with 2+ positional params and hand-built `FooTag{...}` / `FooTag x;` in UI code.
- Formatting: `ContinuationIndentWidth: 2`, so every call in a UI tree (`row(`, `wide(`, `pad(` included) opens an indented block and closes on its own line. Multi-line designated initializers end with a trailing comma, which lays them out one field per line; `glim-lint` enforces it in UI code.
- Accessibility traits: `A11yNode` carries a role (`A11yRole`: text, heading, button, switch, slider, textfield), a spoken value, a numeric range, state and action flag sets (checkable, checked, selected, disabled; activate, increment, decrement) and a live region. Elements report them through `a11yTraits()`; the `a11y({...})` tag adds to them on any element. `A11yNode::role` (the element kind) is renamed `kind`.
- Accessibility preferences: `Store::setPrefs` takes `A11yPrefs` (reduce motion, high contrast). Under reduce motion every `Anim` jumps to its target; under high contrast the toolkit defaults for window background and focus ring switch to high-contrast tokens. `themeColor(e, key)` resolves builtin keys with those defaults.
- `host::TestApp::paint`: lets apps that draw the context directly (like the glass example) use the headless probe.
- `host::Config::crashReport` and `crashSink`: crash reports from fatal signals, delivered on the next launch.
- Native integration contract: `host::Embedder` (attach, place, detach) with one shared diff, `syncEmbeds`. Slots are its overlay implementation, `SlotOverlay`; behaviour is unchanged.
- Texture-mode feeds: `paint::Context::wrapSurface` wraps an `IOSurface` that the Metal renderer imports once per image id. `host::Feed` samples the newest buffer whose producer fence has passed (`MTLSharedEvent` on Apple) and never waits; `FeedStats` reports lag, fence misses and dropped buffers.
- Video example (`examples/video`): GPU video in Texture mode under a glass label, with tap to play or pause. A Metal producer on its own queue publishes IOSurface frames through `host::Feed`.
- iOS: run-loop tasks and timers now run under `UIApplicationMain` (they were never drained), so `--drive` works on iOS, and the drive report prints when the drive closes the window.
- Video example on Android: a Vulkan producer on its own device renders the same scene into AHardwareBuffers. The scene source (`clip.scene`) is shared with the Metal producer.
- Linux import seam: `importSurface` takes a `gpu::DmaBuf` plane and imports it on Vulkan (`VK_EXT_external_memory_dma_buf`, explicit DRM modifiers when available). The video example's Vulkan producer runs on Linux with exported dmabufs.
- Web import seam: `importSurface` takes a `WGPUTexture` on Glim's device. The web bundle's `video.html` copies WebGL2-rendered `VideoFrame`s into a ring through `copyExternalImageToTexture` and shows them under glass.
- `gpu::Device::destroyTexture`. The renderer frees textures of released images, so `Stats::textureBytes` and `importedBytes` shrink again.
- `host::Feed::claim(ring)`: picks the buffer a producer writes next, never one a frame may still sample, and supersedes a pending frame only when a newer one is ready. `FeedStats::reuseWaits` counts claims that told the producer to wait.
- Accessibility frames follow `translate()` and `rotate()`, as hit testing does.
- Accessibility increment and decrement: `shell::A11yElement::adjustable`, `Window::setA11yPerform` (replaces `setA11yActivate`, now with an `A11yCommand`), and a toolkit `Adjust{step}` event delivered to the node under the frame. macOS and iOS bridges forward the OS actions.
- Accessibility focus sync: `A11yNode::focusIndex`, `shell::A11yElement::focused` and `A11yCommand::Focus`. App focus moves the VoiceOver cursor on macOS and iOS, and VoiceOver focus moves app focus. `host::shellA11y` takes the current focus.
- Vulkan: imported AHardwareBuffers are acquired from the foreign queue before each frame and released after it, so another producer's writes become visible.
- Android: `glim_app_main(int argc, char** argv)` receives the `args` intent extra (`am start ... --es args "--drive /path"`); stdout and stderr go to logcat (tag `glim`). When the app returns, the activity finishes instead of hanging until an ANR.
- iOS: the app exits when a drive finishes.
- Perspective groups composite as their projected quad (software, Metal, Vulkan, WebGPU) through a new `warp` pipeline, instead of their bounding box. `glim-core` adds `Mat3`, `Mat4::rotateX`, `rotateY`, `perspective`, `projectPlane` and `unprojectPlane`.
- `tilt({.x, .y, .perspective})` turns a node's children in 3D; hit testing, focus and a11y follow the projection (`PushTilt`, op codec v7).
- Fix: a `tap(...)` with a slot tag (`rotate`, `translate`, `tilt`) now receives presses; before, its label swallowed them.
- Native compositor layers (K88): a seat under a 3D transform composites as the native view's own layer. `SlotPlacement` carries `local` and `transform`, and `Window::positionSlot` takes them. macOS hosts the view in a transformed layer and routes input through the projection; iOS sets the layer transform; other shells place it flat.
- macOS: standard App, Edit and Window menus. Cmd+Q closes the windows so the host ends cleanly (it used to `exit()` under the app, or do nothing); Cmd+H, Cmd+M, Cmd+W and Ctrl+Cmd+F work; Cut, Copy, Paste and Select All reach the focused Glim field (new `TextOp::SelectAll`) or a native seat such as WebKit.
- `slider({.value, .lo, .hi, .step, .width})`: press or drag on the track, Left/Right and screen-reader adjust step it; Slider a11y role.
- `glass({.merge = false})` keeps a plate's own outline next to close neighbors (op codec v8).
- `tilt({.fit = true})` shrinks the turned content until its projection stays inside the node's box, so the near edge never covers neighbors; paint and hit testing share the scale.
- Android: the run loop handles input that arrived during a frame before rendering the next, so a slow frame no longer turns a tap into a long press.
- WebView example: a Glim address bar (owned text field), Local/Site, Go, Reload, load progress and a fitted tilt slider drive the page; chrome glass does not merge; `WKWebView` is a native layer on Apple.
- Owned text input (N8.1): `textField({.value = State<TextEdit>})` with IME composition. `TextEdit` and its pure edit functions live in `glim/toolkit/TextEdit.h`. `Screen::text` and `Screen::textFocus` route changes to the focused field. `Window::setTextInput` and `setTextInputCallback` are the shell contract (`glim/shell/TextInput.h`). macOS implements `NSTextInputClient`; the other shells are no-ops for now.
- Toolkit walks are linear: containers give every child box from one flow (`childBoxes`). Before, a focus, hit, a11y or paint walk re-flowed all siblings per child; a 400-row list walk took 171 ms in Debug, now 3.1 ms.
- WebView example (`examples/webview`): Slot on Apple (`WKWebView` through the seat factory) and Texture on Android (WebView in a `VirtualDisplay`, read through an `AImageReader` of `AHardwareBuffer`s into `host::Feed`, with touches forwarded as `MotionEvent`s).
- Android: `shell::androidActivity()` returns the JavaVM and activity, for app-owned Java glue. `glim_add_example(... JAVA dir)` compiles the dir to `classes.dex` with `javac` and `d8`.
- `seat(...)` with tags (`expand()`, `semantic()`) now emits its slot. Before, the wrapper hid it and no native view attached.
- `LayerProps::width` and `height` set the layer's size (default 320×180).
- The GPU renderer logs a failed surface import once per image and stops retrying it.
- `@glim/native:run`: `smokeTap` taps the screen center halfway through an Android smoke, and `smokeLog` lists logcat patterns that must appear.
- `layer({.image, .onInput})` forwards pointer and wheel input in component space (`LayerInput`, `layerInput(box, ev)`); the wheel reaches a handler under the pointer before scroll views.
- Accessibility reaches the OS: `Window::setA11y` takes `shell::A11yElement`s (role, label, value, window-logical frame, parent, checked, disabled). macOS builds `NSAccessibilityElement`s under the view, with hit testing and press; iOS and tvOS build flat `UIAccessibilityElement`s with traits and activate. `Window::a11yActive()` turns true once the OS asks, and only then does `host::run` walk the tree, map it with `host::shellA11y` and publish it; a screen-reader activation taps the node's centre. Android, Linux and web keep no-op bridges.
- A11y graft for embedded components: an element's `a11yExport()` returns an `A11yExport` (nodes in its own space plus that space's size). `a11yNodes` grafts the nodes after the host node with boxes mapped onto it, and `A11yNode::parent` links them. `layer({.a11ySubtree})` exports from a Layer. The video example exports what the clip shows.
- Present seam: `Window::present(PresentRequest, done)` shows system-owned UI and `done` receives a `PresentResult` (done, cancelled, unsupported, busy) on the main thread; `dismissPresented()` closes it. The share sheet is the first kind: `NSSharingServicePicker` on macOS, `UIActivityViewController` on iOS. tvOS, Android, Linux and web answer unsupported. `host::run` provides a `host::Presenter` in the Engine, and `host::present(e, request, done)` reaches it from any handler. The video example has a Share button that shows the result.
- Hit testing follows `translate()` and `rotate()`: pointer, focus capture and wheel routing map the window point into each node's paint space, and handlers receive pointer and wheel events in that space. Before, transformed children were hit where they sat before the transform. `hitWithBox` now returns `HitAt` (node, box, `toNode`).
- Tracing: `glim/trace.h` spans and counters go to os_signpost (Apple), ATrace (Android), `performance.measure` (web, opt-in) and a Chrome trace JSON file when `GLIM_TRACE=<path>` is set. The host loop traces its frame phases and per-frame counters.
- `paint::Stats` reports renderer GPU memory: `textureBytes`, `importedBytes`, `targetBytes`. Vulkan now measures GPU time with timestamp queries (`gpuMs`); `Renderer::stats()` returns by value.
- Polyline flattening is memoized on world points, width and pitch: infotainment's full-redraw CPU time drops from 9.5 to 7.9 ms with identical output.
- Probe `bench N gpu`: full-redraw medians for draw and GPU time, draws, instances and memory. `bench` now reuses one paint context across frames, as the host does.
