# Changelog

Glim uses semantic versioning. The version is `project(glim VERSION x.y.z)` in `CMakeLists.txt`, and `packages/glim-web/package.json` matches it. `CHANGELOG.md` has a section for that version. `pnpm release-check` fails if the section is missing, or if a header is added or removed under `packages/*/include` without updating `cmake/public-headers.txt`.

Before 1.0, a new minor version may change the API. A patch version does not.

The public C++ API is those headers. A configured package installs the headers of the targets it built, including one shell. Anything else — sources, examples, tools — is not public. `@glim/web` exports `GlimCanvas`.

Pushing the tag `vX.Y.Z` publishes the changelog section as a GitHub release. The tag does not publish to npm. `pnpm web-pack` is a dry run; the tarball is a CI artifact.

## [0.1.0] - 2026-11-12

First versioned release of the public packages.

- CMake package, Apple xcframework, Android prefab AAR, and `@glim/web` (loader and glass wasm).
- Public C++ headers are the files under `packages/*/include`, listed in `cmake/public-headers.txt`.
- Every bundle ships `LICENSE` and `THIRD_PARTY_NOTICES.md` (Inter, stb, volk), generated by `node tools/notices.mjs --write`.
- `host::Config::power`: frame-rate cap and low-power mode.
- `pushOpacity`: fades everything painted until the matching `pop`. A lone fill or image folds the fade into its color, with no offscreen pass.
- Tag factories take named params: `glass`, `shadow`, `effectGlow` and `rotate` take their tag struct (`glass({.radius = 16, .tint = t})`). `glassClear`, `glassMetal` and `glassWater` are gone; use `glass({.clear = true})` or `.material`. `glim-lint` now rejects tag factories with 2+ positional params and hand-built `FooTag{...}` / `FooTag x;` in UI code.
- Formatting: `ContinuationIndentWidth: 2`, so every call in a UI tree (`row(`, `wide(`, `pad(` included) opens an indented block and closes on its own line. Multi-line designated initializers end with a trailing comma, which lays them out one field per line; `glim-lint` enforces it in UI code.
- Accessibility traits: `A11yNode` carries a role (`A11yRole`: text, heading, button, switch, slider, textfield), a spoken value, a numeric range, state and action flag sets (checkable, checked, selected, disabled; activate, increment, decrement) and a live region. Elements report them through `a11yTraits()`; the `a11y({...})` tag adds to them on any element. `A11yNode::role` (the element kind) is renamed `kind`.
- Accessibility preferences: `Store::setPrefs` takes `A11yPrefs` (reduce motion, high contrast). Under reduce motion every `Anim` jumps to its target; under high contrast the toolkit defaults for window background and focus ring switch to high-contrast tokens. `themeColor(e, key)` resolves builtin keys with those defaults.
- `host::TestApp::paint`: lets apps that draw the context directly (like the glass example) use the headless probe.
- `host::Config::crashReport` and `crashSink`: crash reports from fatal signals, delivered on the next launch.
- Native integration contract: `host::Embedder` (attach, place, detach) with one shared diff, `syncEmbeds`. Slots are its overlay implementation, `SlotOverlay`; behaviour is unchanged.
- Texture-mode feeds: `paint::Context::wrapSurface` wraps an `IOSurface` that the Metal renderer imports once per image id. `host::Feed` samples the newest buffer whose producer fence has passed (`MTLSharedEvent` on Apple) and never waits; `FeedStats` reports lag, fence misses and dropped buffers.
- Tracing: `glim/trace.h` spans and counters go to os_signpost (Apple), ATrace (Android), `performance.measure` (web, opt-in) and a Chrome trace JSON file when `GLIM_TRACE=<path>` is set. The host loop traces its frame phases and per-frame counters.
- `paint::Stats` reports renderer GPU memory: `textureBytes`, `importedBytes`, `targetBytes`. Vulkan now measures GPU time with timestamp queries (`gpuMs`); `Renderer::stats()` returns by value.
- Polyline flattening is memoized on world points, width and pitch: infotainment's full-redraw CPU time drops from 9.5 to 7.9 ms with identical output.
- Probe `bench N gpu`: full-redraw medians for draw and GPU time, draws, instances and memory. `bench` now reuses one paint context across frames, as the host does.
